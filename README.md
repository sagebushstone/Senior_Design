# Senior Design - CincyGuard
Repo for the senior design project in BSIT.

### Project Objectives
There will be a crime map web application that UC students will be able to check in order to tell what areas around their location are safe or not. There will be a heat map to show the most crime heavy areas, and location markers for specific recent crimes including what type they are. That way students are able to know where to be more cautious or where they can feel most safe when traveling around campus or the surrounding areas. This will answer the question, “what crimes have occurred in my area in the past, so I know which areas may be less safe?” Overall, the goal of the project is to foster feelings of safety around campus and the city in general.

### Scope
This is limited to the city of Cincinnati and UC students. This is a web app so it will not have real-time location tracking via GPS. Also, the data for the app is currently planned to be a historical view of crime data, not of live updates.
